Ask on WhatsApp
How do guests open it? +

They tap the link you send on WhatsApp. It opens directly in their phone’s browser, with nothing to download or sign up for.

Can some guests see only some events? +

Yes. Every multi-event order comes with separate links (for example Walima-only, Baraat + Walima, and All Events) so each group sees only the ceremonies they are invited to.

Do I need to type the Urdu myself? +

No — simply fill the order form in English. Our calligraphic engine prepares all Urdu Nastaliq names, parents' titles, and event headings for you.

Can I change details after ordering? +

Yes. If a venue or timing changes, let us know and every link you have already shared updates immediately.
